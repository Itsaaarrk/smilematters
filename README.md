# Smile Matters: multi-branch website and appointment system mockup

Design mockup (Standard Package) for the Smile Matters clinics:

- **Pasig** · Smile Matters Dental Care Center (main branch)
- **Marikina** · SMILE 2.0 by Smile Matters
- **Caloocan** · Smile Matters Dental Studio

- **Live demo:** https://itsaaarrk.github.io/smilematters/ (after GitHub Pages is turned on)
- **Admin dashboard:** `admin.html` (pick any account, any password)

All data is sample data stored in the visitor's browser. Use "Reset demo data" in the top ribbon to start over.
Clinic details, logos, photos and reviews come from the clinics' public Facebook pages.

Run locally: open `serve.bat` (needs Python), then visit http://localhost:8080.
